# Architecture Decision Records

Architecture Decision Records capture decisions that shape the project over time.

Use short, numbered files:

```text
0001-record-architecture-decisions.md
0002-establish-repository-structure.md
```

Each ADR should include:

- Status.
- Context.
- Decision.
- Consequences.

ADRs should be updated only when correcting the record. Superseding decisions should usually create a new ADR.
